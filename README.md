## Project 1: DataGuard

**Cloud-Based Data Redundancy Removal System**

A Python-based system designed to identify duplicate and potentially conflicting records before they are stored in a database.

**Key features:**
- Duplicate record detection.
- Identification of potential data conflicts.
- Validation of incoming records.
- Prevention of redundant data insertion.
- REST API implementation.

**Technologies:** Python, FastAPI, SQLite, SQLAlchemy.

**Project directory:** `CodeAlpha_DataRedundancyRemovalSystem/`

## Project 2: SecureGuard

**SQL Injection Detection and Data Leak Prevention System**

A Python-based security application designed to detect suspicious SQL injection patterns and support safer handling of application data.

**Key features:**
- SQL injection pattern detection.
- Input security validation.
- Security-focused API implementation.
- Data protection mechanisms.
- Web-based security dashboard.

**Technologies:** Python, FastAPI, SQLite, HTML, CSS, JavaScript.

**Project directory:** `CodeAlpha_SQLInjectionSecuritySystem/`
